# Исторические файлы

Эти два файла из исходного ZIP сохранены только для сравнения. Расширение .txt намеренно исключает случайное применение. SQL не соответствует новой схеме (деньги теперь целые копейки, есть revision и таблицы импорта). Старый Render free template не обеспечивает постоянную SQLite и не используется. Текущая установка описана в ../SETUP_MAC.md, контейнер — в ../DEPLOYMENT.md. Никогда не применять исторический SQL к новой базе.
