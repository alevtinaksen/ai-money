# Изменения относительно исходного ai-money-clean.zip

Дата:26.09.2026. Исходный ZIP и его контрольная копия не редактировались.
Технический аудит сохранён в docs/audit. Там номера строк относятся к исходнику.

| Область | Было | Стало |
| --- | --- | --- |
| Личность пользователя | query/header/demo могли выбирать ID | подписанный Telegram или отдельный loopback-only локальный профиль |
| Деньги | отрицательные суммы, потерянные параллельные изменения | строгие положительные суммы, целые копейки, атомарные SQL изменения, ограниченный остаток |
| Редактирование | чужие ссылки и неизвестный upsert | проверка владельца, revision и конфликт409 |
| Повтор запроса | недостаточная защита/локальные копии | client_id+fingerprint, tombstone не допускает воскрешения удалённой операции |
| Начальные данные | исторические демооперации создавались чтением | обычные GET без изменений; явный onboarding только нулевой счёт/общие категории |
| Интерфейс | сетевые ошибки выглядели успехом, постоянные локальные overrides | сервер — источник истины, явные ошибки и повторный вход, подтверждения |
| Аналитика | последний список и фиксированные курсы | полный SQL-период, отдельные валюты, стабильный UTC-контракт |
| AI/чек | фиктивная сумма и автоматическая запись | проверяемый черновик, Gemini только при явном включении, лимиты/timeout |
| Telegram | process dict и чувствительные URL | долговечный черновик, TTL, подтверждение атомарного пакета, чистый URL |
| БД | скрытое переключение на новую SQLite | отказ при недоступной БД/неизвестной старой схеме |
| Эксплуатация | несколько poller, self-ping, отсутствующий UI в образе | отдельный poller, readiness БД, multi-stage образ, backup/restore |
| Разработка | крупные связанные модули, мало проверок | финансовые/импортные/интерфейсные модули, регрессии, lint, CI и проектный Antigravity комплект |
| Банковские данные | нет устойчивого процесса | ограниченный CSV review→confirm с защитой повторов |

Рефакторинг выполнялся вместе с исправлениями, поэтому это **новая версия контракта**, а не побайтно совместимая замена старого API.
Остались отдельные задачи: автоматическая миграция старой действующей БД, пользовательская временная зона отчётов, банковские адаптеры, сверка выписки, связанный refund, batch undo и публичная эксплуатация. Они не замаскированы под реализованные функции.
