# Проверка качества

`python3 scripts/project.py quality` выполняет последовательно: Ruff для bot/app, bot/tests и scripts, синтетические regression tests toolkit, проверку размеров модулей, backend pytest, frontend test --run и production build frontend. Каждый шаг обязателен; отсутствие Ruff, npm, pytest, test script или зависимостей дает FAIL. Отчёт содержит отдельные статусы и отпечаток исходников. Изменение файлов во время проверки тоже дает FAIL. Кеши Ruff/pytest, .DS_Store, временные файлы редактора и артефакты сборки не меняют отпечаток; исходники и тесты учитываются.

`python3 scripts/project.py preflight` требует все обязательные PASS, тот же отпечаток и отчет не старше 24 часов. Команда ничего не разворачивает. Это локальная защита от случайно устаревшего отчёта, не система аттестации и не защита от намеренного редактирования отчета. Для релиза нужны отдельные проверки окружения, секретов, миграций, пользовательского пути и явное разрешение на публикацию.

CI использует Python 3.12 и Node 22 на Ubuntu. Сам файл CI не доказывает успешный удаленный запуск. Ruff использует pyproject.toml; lint — обязательный статус для preflight. Старый отчет без lint больше не проходит.

Тесты toolkit охватывают неверный workspace hook, разделение synthetic/live markers, отсутствие записи секретов, ограниченные исключения размера, свежесть preflight, сохранение чужих hooks, согласованный SQLite WAL backup, checksum и отказ перезаписи существующей базы. Поведение реальной модели по навыкам и native IDE hooks на Mac остается UNVERIFIED до выполнения шагов SETUP_MAC.md.

Документирование результата: перечислить выполненные команды и итог, отдельно указать skipped/unavailable, текущую дату и окружение. Не заменять функциональную приемку зеленым build или существованием файла конфигурации.

PreInvocation hook выполняет реальную проверку размеров и имен перед вызовом модели. Findings ограничены восемью сообщениями по 400 символов; полный список выводит scripts/structure_check.py. Проверка не меняет исходники. Ее синтетические тесты отдельно доказывают отсутствие переписывания исходника и различение ошибки сканирования от успешной проверки. Живая активация IDE остается отдельной приемкой.
