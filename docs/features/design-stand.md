# Локальный дизайн-стенд

`Start_Design_Stand.command` или `python3 scripts/preview.py` собирает текущий frontend,
запускает отдельный API на127.0.0.1:8011 и стенд на127.0.0.1:8766.
Порты можно переопределить через PREVIEW_API_PORT/PREVIEW_PORT; занятые порты дают
ошибку вместо подключения к чужому процессу. Требуются готовые локальные зависимости.

База только `work/design-stand/finance.db`. Telegram updates и облачное распознавание
выключены независимо от bot/.env. Реальный токен, ключи и пользовательская база
не используются. Стенд не является опубликованной Mini App или настоящим ботом.

Файловый сервер разрешает только index стенда/приложения и публичные assets/fonts/design
из dist. `.env`, исходники, каталог Git, listing, traversal и symlink escape запрещены.
Wildcard CORS отсутствует; проверяются Host/Origin. API proxy ограничен loopback HTTP
origin и размером тела, сохраняет authorization, метод, статус и response Content-Type.
Этот сервер применяется для локального просмотра, а не production deployment.

Кнопка «Войти локально» теперь использует `/api` того же origin через proxy. Сценарии
слева отправляют проверенный postMessage в приложение; оно подтверждает реальный переход
или объясняет отказ. Открытая форма, загрузка, запись и неопределённый результат записи
защищены от замены. Менеджер категорий/экспорт открываются через существующие настройки,
аналитика/валюты — через главную; дополнительные экраны не выдуманы.

Симулятор справа явно сообщает, что бюджет не изменён. Он не отправляет Telegram updates
и не заменяет настоящую аудиоприёмку. Ввод отображается как текст, не исполняемый HTML.

Проверки: scripts/tests/test_preview_server.py (закрытые файлы, traversal, symlink,
публичные ресурсы, Host/Origin, ограниченный API proxy); test_preview_launcher.py
(изоляция DB/credentials/mode); frontend previewNavigation/creationRetry tests.
preview включён в Ruff и проверку размеров модулей общего quality.
