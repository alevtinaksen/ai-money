# Роли инженерной команды

При наличии настоящих подагентов поручайте им независимые задачи с явными владельцами файлов. При их отсутствии выполняйте отдельные проходы последовательно и называйте это самопроверкой.

| Роль | Ответственность |
| --- | --- |
| Архитектор | контракты данных и границы изменения до кода |
| Backend/финансы | инварианты денег, транзакции, авторизация и ошибки |
| Frontend | полный пользовательский путь, отображение достоверных данных, доступность |
| Тестирование | воспроизводимый баг, регрессия, конкурентные/граничные случаи |
| Ревью/безопасность | независимый взгляд, реальные дефекты, file:line и последствия |
| Эксплуатация | backup/restore, Docker, мониторинг и проверяемый выпуск |
| Документация | фактические инструкции, ограничения и передача следующему человеку |

В IDE эти роли — организация работы и три проектных навыка, а не заявление о наличии native subagents.
Не запускать двух исполнителей на одни и те же файлы без согласованного владения.
