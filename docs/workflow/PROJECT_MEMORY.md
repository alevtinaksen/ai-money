# Память проекта

Это общие инженерные решения проекта, не скрытая память AI-приложения.

- Один backend обслуживает Telegram и веб. Финансовые изменения проходят через FinanceService.
- Деньги в БД — целые копейки. Сумма операции положительная; остаток может быть отрицательным в установленном диапазоне.
- Перевод — два своих счёта одной валюты. Валюты не суммируются; FX требует отдельного контракта.
- Начальный остаток счёта не равен доходу месяца.
- Авторизация: проверенное Telegram initData; локальная разработка — отдельный профиль только с loopback.
- AI предлагает; человек подтверждает. Успешный текст ответа или HTTP200 не доказывает финансовый результат.
- История/остатки хранятся на сервере. Ошибка сети не создаёт локальную «успешную» запись.
- Даты API имеют UTC timezone; отчётный месяц пока UTC.
- Импорт MVP — стандартный CSV, не универсальный банковский XML/PDF/API.
- Старые финансовые данные не мигрируют автоматически; backup, экспорт и сверка обязательны перед переносом.
- Независимое ревью обнаружило реальные ошибки даже после зелёных тестов: обрезанный preview, UTC-сдвиг, смена счёта импорта, неверная подпись валюты. Сохранять эти регрессии.
- Короткие модули нужны для понятной ответственности. Само количество файлов не повышает качество.
- Официальные interfaces Antigravity проверены26.09.2026; live activation зависит от установленного клиента. Разработка вIDE и GeminiAPI внутрибота — разные подключения.

Обновлять этот документ только проверенными решениями, без секретов и исходных банковских записей.
