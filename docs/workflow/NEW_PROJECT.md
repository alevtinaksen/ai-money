# Новый сайт, бот или приложение

Для нового проекта есть небольшой общий шаблон toolkit/new-project. Это правила работы, не код финансового бота.

Попросите Antigravity: «Создай новый проект в отдельной папке. Возьми общие правила из toolkit/new-project, сначала проверь, нет ли моих существующих AGENTS.md/.agents/rules. При конфликте покажи разницу, сохрани мои правила. Определи стек по задаче, настрой подходящие тесты и единую quality-команду. Не копируй финансовую базу, ключи или личные настройки из AI Money. Проверь структуру, сделай минимальный рабочий результат и реальный smoke».

Шаблон намеренно не обещает один и тот же тестовый скрипт для Python, React, мобильного приложения и любого будущего стека. Инструкции о финансовом ядре остаются только в AI Money. Native hooks/MCP активируются отдельно в новом workspace по подтверждённой схеме IDE; глобальная конфигурация не перезаписывается.
