# Бэкап классического дизайна (Classic Blue Design)

Этот каталог содержит исходные компоненты предыдущего интерфейса приложения (до внедрения неоново-лаймового дизайна):

- `DashboardScreen.tsx` — классический главный экран со скругленными круглыми индикаторами категорий, всплывающим меню и плавающей навигацией.
- `AccountsScreen.tsx` — классический экран счетов с группировкой и плавающей кнопкой перевода.
- `App.tsx` — точка входа и подключение экранов.

## Способы восстановления:
1. Из этих файлов в каталоге `frontend/src/backups/classic_blue_design/`.
2. Из специальной Git-ветки: `git checkout backup-classic-design`.
