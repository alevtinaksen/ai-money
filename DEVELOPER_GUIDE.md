# Для следующего разработчика

Актуальная документация начинается с [docs/README.md](docs/README.md).
Операционные правила — [AGENTS.md](AGENTS.md), проверка — [docs/QUALITY.md](docs/QUALITY.md).

Старые обещания и архитектура исходного ZIP заменены фактическими контрактами.
Исторический аудит находится в docs/audit; он описывает исходник, а не текущий статус реализации.
При конфликте руководств использовать текущие feature contracts и результаты исполняемых тестов.

Главное правило: деньги меняет только финансовый сервис внутри транзакции БД.
UI, AI и импорт не вычисляют собственную независимую финансовую книгу.
