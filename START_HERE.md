# Алина, начните здесь

В этой папке уже подготовлены приложение, проверки и инструкции для вашего AI-помощника.
Откройте **всю папку ai-money** в Antigravity, а не один файл.

Можно сказать помощнику:

> Прочитай AGENTS.md, README.md и docs/SETUP_MAC.md. Помоги запустить этот проект на моём Mac. Проверь версии Python и Node, выполни локальный setup и doctor. Сохраняй мои существующие настройки. Не проси присылать ключи в чат. После запуска пройди создание счёта, расход и импорт тестового CSV. Запусти quality. Отдельно проверь, что правила, навыки и hook реально включились в моей версии Antigravity. Не объявляй готовым то, что не проверил.

## Самый короткий путь

1. Установить Python 3.12+ и Node.js 22+ с официальных сайтов. Если уже установлены — проверить версии.
2. В Terminal в этой папке выполнить: python3 scripts/project.py setup
3. Выполнить: python3 scripts/project.py doctor
4. В первом Terminal: python3 scripts/project.py backend
5. Во втором Terminal: python3 scripts/project.py frontend
6. Открыть http://127.0.0.1:5173 и нажать «Войти локально».
7. В разделе «Счета» создать свой тестовый счёт. Начальный остаток не является доходом.
8. Добавить тестовый расход, проверить и подтвердить сумму. Затем выполнить quality.

Сначала используйте вымышленные данные. Для проверки импорта есть docs/examples/bank-import.csv.
После импорта запишите уже подтверждённые операции повторно не нужно: защита от дублей существует, но совпадение без банковского ID требует внимания человека.

Если установка остановилась, передайте помощнику текст ошибки **без содержимого .env**.
Сон или выключение Mac останавливает доступность бота. Для работы круглосуточно нужен отдельный сервер.

## Как просить о новой функции

> Сначала покажи план и что может сломаться. Сделай небольшое изменение, добавь тест реального сценария, обнови документацию и выполни quality. Проверь структуру папок и размеры файлов. Если модуль пора разделить — предложи границы по назначению и выполни безопасный рефакторинг с тестами. Покажи доказательство результата и оставшиеся ограничения.
