# AI Money — комплект для Алины

Личный бюджет: веб-приложение и Telegram-бот используют одну финансовую логику.
Это подготовленный комплект для локального запуска и дальнейшей разработки.
Исходный архив Алины сохранён отдельно без изменений.

**Начните с [START_HERE.md](START_HERE.md).** На Mac нужны Python 3.12+ и Node.js 22+.
Установщик настраивает только эту папку, сохраняет существующие настройки и не требует ключей для ручного локального бюджета.

## Что работает

- Счета с начальным остатком, категории, доходы, расходы и переводы между своими счетами одной валюты.
- Изменение и удаление операций с проверкой версии; архивирование счетов и категорий.
- Хранение денег целыми копейками, атомарное изменение балансов, защита от повторного запроса.
- Полные месячные итоги по каждой валюте, история страницами. Период определяется в UTC.
- Импорт стандартного CSV: сохранённый предварительный просмотр → исключения, категории и комментарии → подтверждение. Повторный банковский ID не создаёт дубль.
- Текст, аудиофайл и фото дают предложения для проверки. Облачный Gemini включается отдельно и требует согласия на передачу данных.
- Telegram-бот в личном чате: сохранённый черновик с подтверждением; повторное нажатие не дублирует запись.
- Проверки качества, резервное копирование SQLite, правила и навыки Antigravity.

## Что включить после установки

Встроенный бюджет на Mac работает без Telegram и без платного AI. Локальный профиль отдельный от Telegram-профиля.
Для бота владелица задаёт BOT_TOKEN у себя, для Gemini — GEMINI_API_KEY и AI_UPLOAD_CONSENT.
Ключи не отправлять в чат, Git или архив. См. [подключения](docs/INTEGRATIONS.md).

В комплекте нет универсального чтения любых банковских XML/PDF/Excel, прямого входа в банк, автоматической конвертации валют, полноценного учёта кредитов или сертификата ISO 27001.
Для старой действующей базы требуется отдельная миграция после сверки: приложение намеренно не меняет неизвестную схему. См. [перенос данных](docs/MIGRATION.md).
